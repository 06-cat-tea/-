# 折纸文学

一个无需构建工具的静态中文小说展示站，包含 10 部示例作品与《雾台照微》21 章演示连载。免费阅读、免费分享、非商业用途。支持书库筛选、随机推荐、个人书架状态、阅读续读、主题字号行距设置、本地书评、作者多章节创作、自动保存、TXT 导出、写作时间与字数记录、灵感便条及备份管理。

站点提供 PWA manifest 和离线服务工作线程，公开页面与演示章节完成缓存后可离线访问。使用系统字体，不加载广告、统计或在线字体。作者预览与备份处理不会上传个人数据；GitHub Pages 自身的访问日志处理见站内隐私说明。

## 本地预览

直接打开 `index.html` 可以查看页面。若要体验离线缓存和 PWA 安装能力，请通过本地 HTTP 静态服务器访问，例如：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。服务工作线程只会在 HTTPS 或 localhost 下启用。

## GitHub Pages 发布

仓库包含 `.github/workflows/pages.yml`。推送到 `main` 分支后，GitHub Actions 会发布静态站点。首次设置仓库时，在 **Settings → Pages → Build and deployment** 里将来源选择为 **GitHub Actions**。发布完成后，页面地址会显示在 Pages 设置页和 Actions 部署任务中。

GitHub Pages 发布的网站是公开可访问的；不要把密码、密钥、私人草稿或其他敏感资料放进站点文件。

## 阅读与展示细节

- 作品先进入简介与目录，支持按章节名或序号搜索、正倒序排列与上次阅读标记。
- “继续阅读”恢复本章位置；手动选择章节从头阅读。阅读页可直接切换章节或返回目录。
- 正文进度独立于书评区，末章显示演示阅读结束提示。
- 技术展示声明首次访问显示，也可从书库提示或页脚重新打开；支持弹层键盘焦点管理。
- 本机存储不可用时退回当前页面内存，并提示及时备份；不会提供虚假的账号登录。
- 页面与章节优先联网更新，离线时仅使用当前版本缓存。
- 本地原始稿件目录 `锦鲤/` 已加入忽略规则；公开页面仅使用 `novel-data/` 中的演示内容。
- Pages 发布流程只打包指定的静态页面、图标与演示章节文件。

## 本地系统与代码结构

- `assets/catalog.js`：演示书库与后端端点预留；`API_BASE` 默认为空。本次本地系统不调用后端。
- `assets/store.js`：第 3 版本地数据、旧草稿及第 2 版迁移、备份验证与合并。迁移保留旧数据及稳定作品/章节 ID，存储失败时提示当前页面暂存。
- `assets/writer.js`：单调时钟计时、本地日期统计、每日净增字数与 TXT 下载工具。
- `assets/app.js`：统一导航、阅读、创作、设置、声明与交互。支持浏览器前进/后退及现有作品链接。
- `assets/site.css` 与 `assets/upgrade.css`：纸色主题、折纸与翻页效果；可关闭动画，并尊重系统减少动态效果偏好。
- 作者作品包含稳定 ID 与有序章节；停止输入一秒后自动保存。书架移除、作品和章节删除可在 12 秒内撤销。保留至少一章。
- 备份格式为 `zhezhi-literature-backup` 第 1 版，包含第 3 版本地数据，并可导入旧版数据；最大 10 MB。导入先展示数量，再按稳定 ID 合并，作品、便条和写作记录保留更新时间较新的版本，重复导入不累加统计。
- 设置页可分别清理书架、足迹、评分/书评、阅读设置、作品、灵感便条、写作记录和每日目标；删除作者作品需再次确认，未勾选的便条与记录保留。

## 作者工具

- 作者中心提供我的作品、灵感便条和写作记录。作品可搜索并按修改时间、名称或字数排序；章节可按标题和序号搜索，上下移动始终使用完整章节目录。
- 编辑页可进入专注模式，按 Esc 退出；Ctrl/Cmd + S 保存正文，便条编辑时保存便条。手机默认折叠章节与作品信息。自动保存不替换正文输入框，中文输入完成后再触发自动保存。
- 全书及本章可导出为 UTF-8 BOM 编码、CRLF 换行的 TXT，包含尚未自动保存的内容。TXT 用于保存与阅读稿件，JSON 备份用于恢复完整数据。
- 编辑正文开始自动计时；连续 120 秒未编辑、切到后台、切换章节或离开编辑页时暂停。计时每 15 秒保存一次，刷新后等待再次编辑。手动暂停后需点“恢复计时”，再编辑正文重新开始。
- 字数按非空白字符计算。每日净增为正文编辑增加量减去删除量，可为负；粘贴计入，整章删除/撤销、排序和导入备份不计入新的创作。未保存修改被放弃时不计入净增字数。
- 记录展示今日、本周、累计时长和近 30 天每日数据，可筛选作品。按浏览器本地日期分日，跨午夜拆分时长，本周从周一开始。每日目标默认 2,000 字，设置为 0 关闭。
- 灵感便条支持独立保存、关联作品、搜索、置顶、编辑、自动保存和删除撤销。关闭编辑弹窗立即保存；删除作品后便条与记录保留并标记原作品已删除，可重新关联便条。
- 所有私人内容继续在浏览器内处理。存储受限时仅在当前页面暂存，TXT 与 JSON 下载仍可用；突然关闭浏览器可能丢失最近一个计时保存周期。

## 浏览器验收

运行 `node tests/author-unit.cjs` 验证迁移、备份去重、计时、跨日统计、净增字数和清理行为，无需额外依赖。安装 Playwright 与 Chromium/Chrome 后执行 `node tests/acceptance.cjs`，浏览器计时验收需支持 Clock API 的 Playwright。也可通过 `PLAYWRIGHT_PATH` 指定现有 Playwright 包路径，`BROWSER_CHANNEL` 指定浏览器（默认 `chrome`）。

验收覆盖旧数据迁移、点击导航、续读、书架、自动保存、多章节排序及删除撤销、离开编辑页、备份恢复、隐私说明、离线缓存、320px/390px 手机布局、减少动态效果、存储受限与章节资源加载失败；新增 TXT 编码及内容、中文输入、专注模式、灵感管理、目标设置、计时跨日/暂停和重复导入验收。截图和结果写入已忽略的 `.cache/acceptance/`，不会发布到网站。
