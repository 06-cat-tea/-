# 折纸文学

一个无需构建工具的静态中文小说展示站，包含 10 部示例作品与《雾台照微》21 章演示连载。免费阅读、免费分享、非商业用途。支持书库筛选、随机推荐、个人书架状态、阅读续读、主题字号行距设置、本地书评、作者多章节创作、跨页保护、全书查找替换、接续写作卡、自动保存、TXT 导出、写作时间与字数记录、灵感便条及备份管理。

站点提供 PWA manifest 和离线服务工作线程，公开页面与演示章节完成缓存后可离线访问。使用系统字体，不加载广告、统计或在线字体。作者预览与备份处理不会上传个人数据；GitHub Pages 自身的访问日志处理见站内隐私说明。

## 本地预览

直接打开 `index.html` 可以查看页面。若要体验离线缓存和 PWA 安装能力，请通过本地 HTTP 静态服务器访问，例如：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。服务工作线程只会在 HTTPS 或 localhost 下启用。

## GitHub Pages 发布

仓库包含 `.github/workflows/pages.yml`。推送到 `main` 分支后，GitHub Actions 会发布静态站点。首次设置仓库时，在 **Settings → Pages → Build and deployment** 里将来源选择为 **GitHub Actions**。发布完成后，页面地址会显示在 Pages 设置页和 Actions 部署任务中。

GitHub Pages 发布的网站是公开可访问的；不要把密码、密钥、私人草稿或其他敏感资料放进站点文件。

## 阅读与展示细节

- 作品先进入简介与目录，支持按章节名或序号搜索、正倒序排列与上次阅读标记。
- “继续阅读”恢复本章位置；手动选择章节从头阅读。阅读页可直接切换章节或返回目录。
- 正文进度独立于书评区，末章显示演示阅读结束提示。
- 技术展示声明首次访问显示，也可从书库提示或页脚重新打开；支持弹层键盘焦点管理。
- 本机存储不可用时退回当前页面内存，并提示及时备份；不会提供虚假的账号登录。
- 页面与章节优先联网更新，离线时仅使用当前版本缓存。
- 本地原始稿件目录 `锦鲤/` 已加入忽略规则；公开页面仅使用 `novel-data/` 中的演示内容。
- Pages 发布流程只打包指定的静态页面、图标与演示章节文件。

## 本地系统与代码结构

- `assets/catalog.js`：演示书库数据，不包含未使用的后端占位配置。
- `assets/store.js`：第 5 版本地数据、旧草稿及第 2/3/4 版迁移、备份验证与合并。迁移保留旧数据及稳定作品/章节 ID，存储失败时提示当前页面暂存。
- `assets/writer.js`：单调时钟计时、本地日期统计、每日净增字数与 TXT 下载工具。
- `assets/app.js`：导航、阅读、设置与公共交互；`assets/author.js` 集中管理作者页面、正文和便条编辑状态。支持浏览器前进/后退及现有作品链接。
- `assets/studio.js`：作品级大纲、人物与关系图、伏笔提醒及历史面板，独立更新局部表单。
- `assets/snapshots.js`：独立 IndexedDB 历史库、事务写入、快照去重和自动版本保留策略。
- `assets/backup.js`：完整与选中历史备份、50 MB 校验及跨存储导入流程；`assets/utils.js` 提供共用统计、合并与状态工具。
- `assets/site.css` 与 `assets/upgrade.css`：纸色主题、折纸与翻页效果；可关闭动画，并尊重系统减少动态效果偏好。
- 作者作品包含稳定 ID 与有序章节；停止输入一秒后自动保存。书架移除、作品和章节删除可在 12 秒内撤销。保留至少一章。
- 备份格式为 `zhezhi-literature-backup` 第 1 版，包含第 5 版本地数据、创作设定及独立历史库中的快照，可导入旧版数据；按 UTF-8 字节校验，单文件最大 50 MB。导入先展示数量，再按稳定 ID 合并，作品、便条、创作设定和写作记录保留更新时间较新的版本，历史快照按稳定 ID 去重，重复导入不累加统计。
- 设置页可分别清理书架、足迹、评分/书评、阅读设置、作品、灵感便条、写作记录、每日目标、创作设定和历史快照；删除作者作品需再次确认，未勾选的便条与记录保留。

## 作者工具

- 作者中心提供我的作品、灵感便条和写作记录。作品可搜索并按修改时间、名称或字数排序；章节可按标题和序号搜索，上下移动始终使用完整章节目录。
- 编辑页可进入专注模式，按 Esc 退出；Ctrl/Cmd + S 保存正文，便条编辑时保存便条。手机默认折叠章节与作品信息。自动保存不替换正文输入框，中文输入完成后再触发自动保存。
- 全书及本章可导出为 UTF-8 BOM 编码、CRLF 换行的 TXT，包含尚未自动保存的内容。TXT 用于保存与阅读稿件，JSON 备份用于恢复完整数据。
- 编辑正文开始自动计时；连续 120 秒未编辑、切到后台、切换章节或离开编辑页时暂停。计时每 15 秒保存一次，刷新后等待再次编辑。手动暂停后需点“恢复计时”，再编辑正文重新开始。
- 字数按非空白字符计算。每日净增为正文编辑增加量减去删除量，可为负；粘贴计入，整章删除/撤销、排序和导入备份不计入新的创作。未保存修改被放弃时不计入净增字数。
- 记录展示今日、本周、累计时长和近 30 天每日数据，可筛选作品。按浏览器本地日期分日，跨午夜拆分时长，本周从周一开始。每日目标默认 2,000 字，设置为 0 关闭。
- 灵感便条支持独立保存、关联作品、搜索、置顶、编辑、自动保存和删除撤销。关闭编辑弹窗立即保存；删除作品后便条与记录保留并标记原作品已删除，可重新关联便条。
- 所有私人内容继续在浏览器内处理。存储受限时仅在当前页面暂存，TXT 与 JSON 下载仍可用；突然关闭浏览器可能丢失最近一个计时保存周期。

## 小说创作工具

- 编辑页的故事工作台包含大纲、人物、伏笔和历史四个标签；桌面默认展开，手机默认折叠，专注模式保留工具入口。打开或使用工具会暂停计时，继续编辑正文后恢复自动计时。
- 全书概览记录主题、主线与结局；章节剧情卡记录目标、冲突与转折，按章节 ID 关联。章节删除后保留卡片，可重新关联到尚无剧情卡的现有章节。
- 人物卡包含姓名、别名、定位、动机与设定备注。人物关系支持单向与双向标签；关系图围绕选中人物展开，可鼠标或键盘切换焦点，完整关系同时显示为文字清单。删除人物会同步移除关联关系，可在 12 秒内撤销。
- 伏笔可指定埋设和回收章节，并标记待回收、已回收或已放弃。本章提示展示剧情目标及安排在本章回收的伏笔；章节删除后关联显示为已删除，记录保留。
- 正文修改后切换章节或离开作品时自动留档，相同内容不重复生成自动快照。每章保留最近 20 个自动版本；手动命名版本只在主动删除或选择清理时移除。历史存于独立 IndexedDB，不占用草稿的 localStorage。
- 历史面板提供当前稿与旧稿的并排预览。恢复前先成功保存当前稿为手动快照，失败则保持正文；已删除章节可恢复为新章节。恢复不回退创作设定，不增加创作字数或启动计时。
- 完整 JSON 备份包含快照。超过 50 MB 时，可勾选历史分批导出；每批包含全部当前数据和所选历史，明确标记部分历史范围，可分别导入且去重。历史库无法读取时，可以明确选择导出不含历史的当前数据。
- 新工具字段一秒自动保存并等待中文输入完成，正文保存不会覆盖创作设定；未变化的稿件不会重写更新时间。历史保存或读取失败会提示，当前稿仍可保存、预览及导出 TXT。
- 删除作品时可选择是否同时删除设定和历史；设置页也可独立清理它们。原有灵感便条和写作记录按各自选项保留。

## 本轮代码简化

- 合并字数统计、较新版本合并和保存状态格式；统计汇总改为单次遍历，共享一次读取的记录。
- 移除未使用的 API_BASE/API_ENDPOINTS、重复贴吧地址、旧写作弹窗计数字样、未引用的封面图片与配色样式。
- 作者状态从主脚本分离；无变化保存、空计时刷盘和重复暂停不再写入存储，补充异步导航完成前的请求校验。
- 浏览器测试共享同一静态服务、下载和导航辅助模块。
- 重构前主脚本为 73,645 字节；当前主脚本为 49515 字节，约减少 33%。作者模块 40461 字节、创作工具 34412 字节、历史模块 5749 字节，备份和公共工具共 7829 字节；这些模块同时承载新增功能。

## 浏览器验收

运行 `node tests/author-unit.cjs` 验证迁移、备份去重、计时、跨日统计、净增字数和清理行为，无需额外依赖。安装 Playwright 与 Chromium/Chrome 后执行 `node tests/acceptance.cjs` 和 `node tests/studio-acceptance.cjs`，浏览器计时验收需支持 Clock API 的 Playwright。也可通过 `PLAYWRIGHT_PATH` 指定现有 Playwright 包路径，`BROWSER_CHANNEL` 指定浏览器（默认 `chrome`）。

验收覆盖旧数据迁移、点击导航、续读、书架、自动保存、多章节排序及删除撤销、离开编辑页、备份恢复、隐私说明、离线缓存、320px/390px 手机布局、减少动态效果、存储受限与章节资源加载失败；新增 TXT 编码及内容、中文输入、专注模式、灵感管理、目标设置、计时跨日/暂停、人物关系图与级联撤销、伏笔提醒、章节重新关联、自动快照保留、恢复前留档失败、含历史及分批备份往返恢复、重复导入和 IndexedDB 受限验收。截图和结果写入已忽略的 `.cache/acceptance/`，不会发布到网站。

## 跨页保护与写作效率

- 同一作品使用 Web Locks 保证单页编辑，其他页面只读；“申请接管”等待原页完成中文输入并保存，5 秒未响应时请先关闭原页。不同作品可并行编辑，所有共享数据写入在全局锁中读取最新状态并提交。失去权限时保留本页稿件；无跨页锁或存储失败的环境使用可导出的临时会话，不写回共享数据。
- 数据保存接口与初始化均为异步；第 5 版自动迁移第 2/3/4 版和更早草稿，保留 ID 及旧存储。章节快照继续使用独立 IndexedDB。
- 作者中心与设置页显示上次发起 JSON 下载的时间和范围，浏览器无法确认最终文件保存。未备份修改满 7 天或正文增删合计满 5,000 字时轻量提醒，可延后 24 小时或关闭。单作品备份仅导出该作品、设定、接续卡、关联便条、记录和快照，导入不改变其他作品与阅读设置；分批历史与 TXT 不标记为完整历史备份。提醒状态只属于本机，不从备份继承。
- 编辑工具栏保留保存、专注、本地预览和更多菜单；记住上次章节、选区和滚动位置。全书查找仅作用于正文，支持当前章、区分大小写、纯文本定位和逐项或批量替换。允许空替换，不递归匹配新文字。全部受影响章节一次留档成功、修订未变化且正文长度合法后才提交；替换按净字数统计，不启动计时。12 秒内可撤销，已有后续修改时通过历史恢复，避免覆盖新稿。
- 历史默认高亮新增、删除和修改段落，可切换完整并排文本；复杂长稿降级为有界段落对比。接续卡每章最多 1,000 字，等待中文输入结束后自动保存，显示末段最多 200 字、本章大纲与待回收伏笔，修改不计正文创作。删除章节后接续卡保留并可重新关联。
- 新模块：`assets/coordination.js` 管理浏览器锁，`assets/backup-status.js` 管理本机备份提醒，`assets/find.js` 提供安全查找替换，`assets/diff.js` 提供有界差异对比。
- 额外执行 `node tests/reliability-acceptance.cjs` 验证多标签页、接管、备份、替换、差异和接续卡；与原有 11 项单元及 36 项浏览器场景一同回归。
